pmap 在 macOS 菜单栏管理 SSH 本地端口转发，使用你现有的 SSH 配置和密钥。支持 macOS 14 及以上、Intel 与 Apple Silicon。

## 开始使用

1. 将 pmap 放入“应用程序”文件夹并打开，点击菜单栏图标。
2. 点击“授权 SSH 文件夹…”，允许访问默认的 `~/.ssh`。若配置或主机验证文件链接到目录外，按提示补充授权。
3. 从主机菜单选择服务器。首次连接主机或需要解锁密钥时，请在终端完成验证；配置含本机命令时，pmap 会另行请求确认。
4. 输入端口并按回车，再用浏览器或客户端验证远端服务。

下载包分为普通版和沙盒版：普通版更接近终端的 SSH 环境；沙盒版受额外的文件与进程访问限制。两版配置独立，请勿同时运行。更换应用前先退出旧版。

## 操作与状态

| 操作 | 作用 |
| --- | --- |
| 输入 `8000` | 本地 `127.0.0.1:8000` → 远端 `127.0.0.1:8000` |
| 输入 `8000:80` | 本地 `127.0.0.1:8000` → 远端 `127.0.0.1:80` |
| 输入 `8000:80#网站` | 添加转发及备注“网站” |
| 单击端口号 | 开启或停止转发；失败时停止重试 |
| 单击备注 | 编辑备注；回车或点击其他位置保存，Esc 取消 |
| 无备注时悬停端口行 | 显示编辑图标，点击添加备注 |
| 点击删除图标 | 停止转发并删除记录 |
| 主机菜单 → 断开 | 断开主机及全部转发，取消待恢复状态 |
| `…` → English / 简体中文 | 切换语言 |
| `…` → 运行信息 | 查看版本与状态，选中文字复制 |
| `…` → 撤销 SSH 文件夹授权 | 断开连接并撤销文件授权，保留端口与备注 |
| 点击退出图标 | 保存记录并关闭连接，下次启动恢复 |

端口范围为 **1–65535**，本地端口不能重复。格式错误时保留输入，显示红色 `port/port:port`；重复端口会高亮已有行。

| 状态 | 含义 |
| --- | --- |
| 主机绿 / 红 / 灰 | 已连接 / 连接失败 / 断开或连接中 |
| 端口绿 / 红 / 灰 | 转发已建立 / 转发失败 / 未开启或主机未连接 |
| 菜单栏圆点 | 按端口顺序轮播各端口状态 |

绿灯表示转发已建立，不保证远端服务正常；请用实际客户端验证。连接中断会自动尝试重连；授权与配置有效时，重启应用会恢复上次主机和期望开启的端口。通知是否显示由 macOS 系统设置控制。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 未找到 config 或没有可用主机 | 检查 `~/.ssh/config` 是否存在，并使用不含点号的具体 Host 别名；详见[配置说明](./docs/CONFIGURATION.md) |
| 无法读取 config / known_hosts | 检查文件权限和内容；若提示需要授权，选择实际文件或链接目标 |
| 缺少 known_hosts 或主机密钥校验失败 | 在终端连接该主机并核验指纹；不要直接删除整个 known_hosts |
| 认证失败 | 先确认终端 SSH 可用，必要时解锁密钥，再重新选择主机 |
| 本地端口被占用 | 关闭占用程序，或删除失败规则并改用其他本地端口；也可先停止该端口，再开启 |
| 绿灯亮但服务无法访问 | 检查远端服务及目标端口，绿灯不代表服务本身健康 |

**Local port in use:** Stop the local program using the port, or use a different local port. pmap retries automatically; you can also stop and restart the failed port.

仍有问题时，从 `…` → “运行信息”选中复制状态，附上复现步骤到[问题反馈](https://github.com/jiyeqian/pmap/issues)。运行信息已脱敏；分享其他截图或配置前，请检查是否包含私人信息。

## 配置与隐私

配置和文件授权保存在本机；pmap 不复制私钥，不向开发者发送数据。撤销授权不会删除 SSH 原文件。详见[配置与兼容性](./docs/CONFIGURATION.md)和[隐私政策](./docs/PRIVACY.md)。
