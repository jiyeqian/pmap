pmap 为现有系统 OpenSSH 环境提供图形控制面板：选择主机，输入 `8000` 或 `8000:80`，开启或停止本地到远程回环地址的端口转发。支持 macOS 14+，构建为 Intel 与 Apple Silicon 通用二进制。

当前改造分支为下一版 0.2.0（5）候选版本；`v0.1.5` 标签保留改造前基线。尚未完成正式 App Store 签名、上传或审核。

## 构建与启动

```bash
cd /Users/jiyeqian/Workspace/pmap
./test.sh
./build.sh
./scripts/verify-bundle.sh pmap.app
open /Users/jiyeqian/Workspace/pmap/pmap.app
```

需要完整 Xcode 工具链。启动新构建前先正常退出旧实例；构建脚本会拒绝替换检测到的运行中输出。图标或签名失败会阻断构建。普通本地包使用临时签名，没有 Apple 公证；这不等同于正式商店分发。

沙盒候选构建：

```bash
cd /Users/jiyeqian/Workspace/pmap
PMAP_SANDBOX=1 ./build.sh
PMAP_REQUIRE_SANDBOX=1 ./scripts/verify-bundle.sh pmap-sandbox.app
open /Users/jiyeqian/Workspace/pmap/pmap-sandbox.app
```

完整 Xcode 工程、真实 SSH 集成测试和人工验收方法见 [商店准备与验收](./docs/APP_STORE.md)。

## 首次使用

1. 未授权时，主面板仅显示“授权 SSH 文件夹…”和退出按钮；不会主动弹框。
2. 点击“授权 SSH 文件夹…”，系统框默认定位 `~/.ssh`，点击“允许”。只接受这个默认目录；不再逐个选择 config 或 known_hosts。
3. 授权后立即读取 `config`，检查实际使用的主机验证文件。仅在符号链接的真实目标因权限不足不可读时，接续弹出目标文件授权框。取消后不循环弹框，错误旁保留补充授权入口。
4. 目录授权有效后进入工作菜单，即使 config 缺失、为空或不可读也不会退回首次授权界面。known_hosts 问题不隐藏主机列表。
5. 配置首次使用时仍需确认可信；请在终端验证主机并解锁密钥。pmap 严格校验主机密钥，不自动接受新指纹或变更的指纹。

目录及外部文件的访问书签会保存，重启后自动恢复；授权失效或执行 `…` → “撤销 SSH 访问…”后返回两栏菜单。撤销会断开受管主机和端口、取消重试与待开启状态，但保留端口列表、备注、语言和偏好，不修改原 SSH 文件。

| 检查结果 | 固定消息或操作 |
| --- | --- |
| 缺少 config | 未找到 config 文件，没有可用主机。 |
| config 无可用主机 | config 文件中没有可用主机。 |
| config 无法读取 | 无法读取 config 文件。 |
| config 外部链接需授权 | 请允许读取 SSH 配置文件 config。 |
| 缺少 known_hosts | 未找到 known_hosts 文件，请在终端验证主机。 |
| known_hosts 无法读取 | 无法读取 known_hosts 文件。 |
| known_hosts 外部链接需授权 | 请允许读取主机验证文件 known_hosts。 |
| 指纹未被信任或不匹配 | 主机密钥校验失败，请在终端验证主机。 |

预检查静态读取 config 和 Include 中的 UserKnownHostsFile，不运行 Match exec 或建立网络连接；默认检查 `~/.ssh/known_hosts`。支持常见路径替换；依赖条件 Match、环境变量或其他动态展开的路径仍由连接时的 OpenSSH 决定。目录外私钥或 Include 的读取错误在对应故障旁处理。SSH Agent、钥匙串和外部命令仍可能受沙盒限制。

## 操作与状态

| 操作 | 行为 |
| --- | --- |
| 输入 `8000` | 本地 `127.0.0.1:8000` → 远程 `127.0.0.1:8000` |
| 输入 `8000:80` | 本地 `127.0.0.1:8000` → 远程 `127.0.0.1:80` |
| 输入 `5432:5432#数据库` | 添加转发并显示备注 |
| 点击端口按钮 | 开启，或停止转发/重试 |
| 点击删除按钮 | 清理转发后删除规则；清理失败时保留规则与错误 |
| 主机菜单“断开” | 断开当前主机及端口，取消待恢复状态 |
| 地球图标 | 切换并保存界面语言 |
| 省略号菜单 | 语言切换、撤销 SSH 文件夹授权、运行信息、使用帮助、隐私政策 |
| 电源图标 | 保存期望状态，异步释放受管 SSH 会话与监听 |

端口绿灯表示转发请求已建立，**不表示远端服务健康**；红灯表示失败；主机未连接时端口为灰。菜单栏圆点按端口顺序轮播，不能代替主机错误详情。端口按钮提供辅助功能名称和状态，长列表支持滚动。

端口范围为 **1–65535**。本地端口不能重复，远程端口可以重复。非法格式及重复本地端口回车后显示红色提示，继续输入即清除提示。`#备注` 在创建时填写，之后以次级灰字显示；悬停端口按钮可查看完整备注。

自动保存端口、备注、选中主机、期望开启状态和语言。正常退出会关闭受管转发；再次启动时，若配置可用、可信，自动连接上次主机并恢复端口。

自动重试仅用于可恢复故障；初次连接失败按 3、6、12、24、30 秒退避，端口转发失败按 5、10、20、30 秒退避。认证、主机密钥及明确禁止转发等错误需要用户处理，再从主机菜单重新选择该主机；失败端口可先点停，再点开启。端口被占用时尽可能显示占用进程，沙盒不允许查询时仍显示端口占用错误。

启动恢复、自动重连固定开启。通知由 macOS 系统设置控制，首次需要发送时申请系统权限。系统允许后，连接断开、重连成功和失败端口恢复会通知；重连成功仅表示主连接恢复，通知中的端口数为待恢复数。系统拒绝权限后需在系统设置中允许。

| 状态 | 含义 |
| --- | --- |
| 主机绿 / 红 / 灰 | 已连接 / 连接失败 / 断开或连接中 |
| 端口绿 / 红 / 灰 | 转发已建立 / 转发失败 / 停止或主机未连接 |
| 菜单栏圆点 | 按端口顺序每 1.5 秒轮播其颜色；主机未连接或无端口时为灰 |

主机失败先检查主机错误；端口失败查看该行悬停提示。菜单栏圆点表示端口状态，不单独表示主机健康。

## 配置与兼容性

普通构建配置：`~/Library/Application Support/Pmap/config.json`。沙盒构建保存在对应应用容器内，应用支持目录由系统 API 确定；两种构建不自动互相迁移配置。旧版文件位于 `~/Library/Application Support/Pmap/config.json`。

旧版核心配置仍可读取：

```json
{
  "host": "myserver",
  "adhoc": [{ "local": 3080, "remote": 3080, "note": "deepseek" }],
  "active": [3080],
  "lang": "zh"
}
```

`host` 是上次主机，`adhoc` 是端口与备注，`active` 是期望恢复的本地端口，`lang` 是界面语言。新授权及连接偏好由程序管理，无需手动填写。

配置原子保存并校验端口。损坏或不支持的配置版本会提示错误并保留原文件，不会静默覆盖。`active` 字段保存用户期望恢复的端口，而不是声称这些端口在任何时刻都实际连通。

pmap 只读系统 SSH 配置和密钥。主机列表沿用 0.1.5 规则：排除含点、通配及否定模式，排除明确指向 `localhost`、`127.0.0.1`、`::1` 的别名；一行多个别名也会过滤。支持有界递归 Include。本机过滤只静态检查 Host/HostName，不执行 Match exec 或 DNS 查询；条件配置需由用户自行确认。含点主机需要使用无点别名。User、HostName、Port、IdentityFile 和 ProxyJump 交给系统 OpenSSH 解析。配置里的 LocalCommand、Agent/X11 转发和额外端口映射被禁用，仅管理面板声明的本地转发。

ProxyCommand 和 Match exec 可能执行程序，因此仅在用户确认信任配置后运行，并仍受沙盒权限约束。完整边界见 [SSH 兼容契约](./docs/APP_STORE.md)。

与 0.1.5 的逐项恢复及保留差异见 [版本差异](./docs/VERSION_COMPARISON.md)。

## 故障诊断

使用 `…` → “运行信息”查看并选中复制脱敏报告。报告包含构建号、主机状态、固定错误类别、端口错误分类计数、配置读取与信任状态，以及仅在需要处理问题时显示的恢复建议。主机故障会明确标记，不会因 Storage/Access 为 false 而被隐藏。

报告不含主机名、地址、端口号、路径、进程名、备注或 SSH 原始输出；只提供建议，不自动修改配置、授权或信任记录。`Access error: false` 不保证 SSH 能读取全部引用文件；主机密钥错误需按报告在终端核对指纹、必要时授权实际 known_hosts。未连接时请选择主机；转发建立后，请用浏览器或客户端确认远端服务。恢复验证应检查主机连通、所需端口为绿，再用客户端确认服务响应；绿灯不保证远端服务健康。通知是否显示由系统授权决定，运行信息中的通知启用状态不等于系统允许通知。未知错误需在本机查看原文，分享前自行脱敏。

## 隐私与发布

pmap 连接你指定的服务器，不向开发者发送遥测，不含广告或统计 SDK。密钥不复制到应用配置；诊断复制不含主机名、地址、路径和备注。完整说明见 [隐私政策](./docs/PRIVACY.md)，通过 `…` → “隐私政策”也可阅读。

商店所需公开隐私政策 URL、发布主体、审核测试服务和加密出口申报仍需在正式提交前确认。现有文案为 [商店材料草案](./docs/STORE_METADATA.md)，不表示已上线。
