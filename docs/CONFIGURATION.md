# pmap 配置与兼容性

## 配置保存与备份

普通版配置：`~/Library/Application Support/Pmap/config.json`。沙盒版保存在对应应用容器内；两版不自动互相迁移配置。

保存格式示例（无需手工编辑）：

```json
{
  "host": "myserver",
  "adhoc": [{ "local": 3080, "remote": 3080, "note": "deepseek" }],
  "active": [3080],
  "lang": "zh"
}
```

`host` 是上次主机，`adhoc` 是端口与备注，`active` 是期望恢复的本地端口，`lang` 是界面语言。新授权及自动连接行为由程序管理，无需手动填写。

配置原子保存并校验端口。损坏或不支持的配置版本会提示错误并保留原文件，不会静默覆盖。`active` 字段保存用户期望恢复的端口，而不是声称这些端口在任何时刻都实际连通。

## SSH 兼容性

pmap 只读系统 SSH 配置和密钥。主机列表规则：排除含点、通配及否定模式，排除明确指向 `localhost`、`127.0.0.1`、`::1` 的别名；一行多个别名也会过滤。支持有界递归 Include。本机过滤只静态检查 Host/HostName，不执行 Match exec 或 DNS 查询；条件配置需由用户自行确认。含点主机需要使用无点别名。User、HostName、Port、IdentityFile 和 ProxyJump 交给系统 OpenSSH 解析。配置里的 LocalCommand、Agent/X11 转发和额外端口映射被禁用，仅管理面板声明的本地转发。

ProxyCommand、Match exec 和 KnownHostsCommand 可能执行程序，因此仅在用户确认后运行，并仍受沙盒权限约束。未使用这些指令的普通配置无需额外确认。静态检测覆盖展开的 Include，保守地检查全部主机段，不执行任何命令；已确认的内容保持不变时不重复提示，内容变化后重新确认。检测到未确认的命令配置时会停止当前受管连接并保留待恢复端口。

沙盒中的 SSH Agent、系统钥匙串、硬件密钥和外部命令可能受系统权限限制，不保证与终端完全一致。pmap 使用非交互认证，不能在应用内输入密钥密码或接受新主机指纹。

## 故障排查补充

认证或主机密钥错误需处理后重新选择主机；端口被占用时可等待重试，或先停止、再开启。配置损坏时请先备份并检查格式，不要直接删除原配置。

运行信息只报告当前已记录的状态；`Access error: false` 不保证 SSH 能读取配置引用的全部资源，通知启用状态也不等于系统已允许通知。它不会自动修改配置或修复故障。
