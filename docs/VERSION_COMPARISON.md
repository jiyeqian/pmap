# 0.1.5 与 0.2.0（3）功能差异

## 对比范围

基线为 Git 标签 `v0.1.5` 的 README 与实现；恢复版本为 0.2.0（3）本地候选。本文记录预期行为及实现，不代表已通过 App Store 审核。普通版和沙盒版使用不同配置目录。

## 已恢复或继续保留

| 功能 | 0.1.5 | 恢复版本 |
| --- | --- | --- |
| 非法输入 | 清空并显示红色格式提示 | 恢复红色、双语的明确格式提示；拒绝越界和错误格式 |
| 重复本地端口 | 红色提示；不添加 | 恢复红色提示；远端端口仍可重复 |
| `3080#deepseek` 备注 | 端口旁灰字显示，创建后只读 | 恢复为端口按钮内的灰字；端口号不压缩；长备注截断，悬停与辅助功能可读完整内容 |
| 连接通知 | 默认申请权限；断开、重连、失败端口恢复时通知 | 三种通知恢复，默认关闭；选项菜单开启时申请权限；系统权限最终决定是否显示 |
| 占用信息 | 转发前检测，可提供占用者信息 | SSH 失败后检查本地回环端口占用并尽可能查询进程；包括只返回通用 mux 错误的情况，查询进程失败仍保留占用提示 |
| 主机列表 | 排除含点、通配、否定及明确本机条目 | 恢复过滤，并应用于 Include 读取结果及多别名；只静态检查 Host/HostName，不运行命令或解析 DNS |
| 默认配置 | 自动读 `~/.ssh/config` | 普通版继续自动读；沙盒版需要用户选择授权，可选任意文件名 |
| 旧配置 | 保存端口、备注、语言、主机和开启状态 | 普通版原目录继续读取；增加手动导入，供沙盒迁移使用；导入前确认替换，不删除源文件，不继承源文件授权或信任 |
| 升级后的恢复 | 启动即恢复旧主机及端口 | 保留旧开启意图；若缺授权或信任则暂停，完成后选择原主机或“恢复上次连接…”继续；关闭“启动时恢复”则不自动恢复 |
| 基础操作 | 添加、开关、删除、自动保存、中英切换、退出清理 | 保留；连接及端口操作增加取消与迟到结果清理 |
| 连接复用及重试 | 主连接复用；主机/端口故障自动重试 | 保留复用；网络等可恢复故障退避重试，可在选项菜单关闭 |
| 状态灯 | 主机三态、端口三态、菜单灯每 1.5 秒按端口轮播 | 颜色语义及轮播保留；端口图形增加可辨识形状；绿仅代表转发建立，不验证远端服务 |
| 文档 | 输入、备注、去重、状态灯、配置示例等说明 | README 补齐，并记录安全、沙盒及迁移差异 |

主机列表过滤沿用旧版用途：Git 域名等入口默认不占列表；确需映射的含点主机请添加无点别名。静态过滤无法完整求值条件 Match、HostName 的运行时展开或 DNS 本机地址。

## 不恢复的原行为及原因

| 原行为 | 恢复版本的处理 | 原因 |
| --- | --- | --- |
| 自动接受新主机指纹 | 严格检查；首次在终端验证 | 防止未核验即信任 |
| 任意错误都自动重试 | 认证、主机密钥、握手及明确禁止转发等错误停止；用户处理后重试 | 避免无效重试；主机重新选择，失败端口先停再开 |
| 默认申请并发送通知 | 用户主动开启时申请 | 避免启动打扰；能力保留 |
| 不经授权读取任意 SSH 资源 | 沙盒内由用户选择资源并保存书签 | 满足沙盒访问约束；符号链接外部目标需另行授权 |
| 无条件运行所有 SSH 配置行为 | 禁用 LocalCommand、Agent/X11 转发和配置自带端口转发 | 只管理面板声明的转发，限制附带行为 |
| 默认继承系统级 SSH 配置 | 指定 `ssh -F` 所选用户配置；不默认读取 `/etc/ssh/ssh_config` | 明确选定配置边界；系统级设置需要显式迁入用户配置或 Include 并授权 |
| 固定 `~/.ssh/pmap-control/<主机>` | 私有目录、短 socket、应用拥有前台 master | 避免路径过长、会话冲突及孤儿后台进程；不保留旧 socket 路径作为接口 |
| 版本号直达主页 | 版本菜单含主页、帮助、隐私 | 集中低频入口 |
| “中 / EN”、退出文字 | 地球、电源图标，配悬停及辅助功能名称 | 用户确认的极简设计 |
| 所有端口不限高度展开 | 长列表滚动 | 避免超出屏幕 |
| 忽略清理失败立即删除 | 清理成功再删除，失败保留规则和错误 | 避免界面与实际监听状态脱节 |

ProxyCommand、Match exec 仍可能运行本机程序，因此需确认配置可信。SSH Agent、钥匙串及外部程序能否工作取决于实际沙盒权限，不承诺与终端完全一致。保留这些限制不等于已经完成商店发布。

## 迁移与验收

1. 正常退出旧实例，再启动仓库中的新构建（本次新版沙盒为 `.build-store/Build/Products/Debug/pmap.app`）；安装在 `/Applications` 的旧版不会自动替换。
2. 沙盒版在 `…` → “导入旧版配置…”选择旧版 `~/Library/Application Support/Pmap/config.json`，确认替换。已有端口会被替换，原文件不变；取消不改变数据。
3. 选择并授权 SSH 配置及必要的外部文件。点击“恢复上次连接…”或选择原主机，确认信任；检查旧备注与原开启端口恢复。
4. 输入 `235dagg`、`0`、`65536` 应显示红色格式提示；输入 `3080#deepseek` 应显示备注，再输入 `3080` 应提示本地端口已映射。
5. 检查含点、本机别名不出现；增加普通远程别名后重新打开面板可见。
6. 开启通知并允许系统权限，检查断线、重连及失败端口恢复通知。单元测试验证通知事件；系统通知横幅取决于权限、专注模式等，需人工验收。
7. 正常退出再启动，检查原主机、开启端口和语言恢复；用实际客户端确认远端服务。

自动测试、原生界面检查与真实 SSH 集成各自覆盖不同范围；不将单元测试通过等同于用户真实服务或系统通知已验收。

## 0.2.0（4）诊断补充

“复制脱敏诊断”增加主机状态与错误类别、端口错误分类计数、配置读取/信任状态和恢复/重试/通知偏好；报告附双语恢复步骤与验证方法。主机密钥错误的引导区分首次信任、指纹变更和沙盒 known_hosts 授权，未自动推断具体根因，也不自动修复。所有动态错误关联值和 SSH 原文均省略。此前构建 3 的验证记录仍仅代表该构建；构建 4 的 74 项测试（13 个套件）及双架构沙盒构建、包检查通过。新版独立输出为 `.build-store/diagnostics/Build/Products/Debug/pmap.app`，未覆盖构建 3 或正在运行的旧包；系统通知和用户真实服务的验收边界不变。

## 0.2.0（5）文件夹授权简化

取代构建 3/4 的任意配置文件选择流程：未授权只显示“授权 SSH 文件夹…”与退出；用户确认默认 `~/.ssh` 后显示工作菜单。移除常驻“选择配置”和通用“授权文件”，保留按错误定位的补充授权，以及低频“撤销 SSH 访问…”。撤销保留端口和备注，断开主机/转发并取消待恢复状态。

授权后立即检查 config 和实际 UserKnownHostsFile；读取因权限不足失败的外部符号链接目标才接续请求授权。取消不循环弹框，缺失/无主机/读取失败使用 README 中的固定双语消息；known_hosts 问题不隐藏主机。配置信任和服务器指纹核验仍与文件访问授权分开。

真实原生沙盒对照已完成，使用独立 Bundle ID 和无密钥虚构目录（.ssh/config 和 .ssh/known_hosts 均指向同级 targets 中的真实文件）：

- 初始只有授权按钮和退出，系统框默认进入 .ssh；取消后保持两栏。
- 只授权 .ssh 后，读取外部 config 被拒绝，立即接续真实 config 授权框。
- 取消 config 授权后不循环弹框，工作菜单保留“无法读取 config”及重试入口。
- 单独授权 config 后可读到 sandbox-demo，外部 known_hosts 仍被拒绝并接续请求；取消时主机列表仍保留。
- 分别授权两个真实目标后错误消失；正常退出重启后，三个书签均恢复，主机与端口备注正常，无重复授权框。
- “撤销 SSH 访问…”确认后回到两栏，端口/备注保留；测试过程没有连接用户真实服务器或读取真实私钥。

开发用实际窗口截图：[未授权](./screenshots/folder-onboarding.jpg)、[授权后](./screenshots/folder-authorized.jpg)。此前普通单元测试中的符号链接检查不作为沙盒权限边界的证明。

构建 5 最终验证：80 项测试（14 个套件）通过；覆盖目录授权/失效、固定消息、known_hosts 路径、普通权限拒绝、断链和恢复记录。真实状态栏面板也验证了“点击授权入口 → 在默认 .ssh 确认 → 自动出现工作菜单”，不需要再点击状态栏图标。普通及沙盒双架构包均检查通过；测试专用入口不包含在交付包中。

本次沙盒交付：`.build-store/folder-release/Build/Products/Debug/pmap.app`；普通交付：`.build-store/pmap-folder-normal.app`。未覆盖正在运行的旧版本或 `/Applications`，未自动提交或推送。系统指纹验证和实际服务器登录仍由用户在真实环境验收。

- 菜单顺序：English / 简体中文（显示目标语言）、撤销 SSH 文件夹授权、分隔线、运行信息、使用帮助、隐私政策；不显示省略号后缀。
- 移除旧版配置导入入口及启动恢复、自动重连、通知开关。启动恢复与自动重连统一开启，包括此前关闭的旧配置；系统通知授权控制通知显示。
- 运行信息始终可用：系统提示框展示完整脱敏报告，文字可选中复制，仅保留“关闭”按钮。帮助打开项目主页。
- 保留撤销授权确认，说明关联文件授权、配置信任与主机和端口断开的范围。

### 提示框统一

- 隐私说明改为两段，集中说明本机保存、私钥不复制、不向开发者发送数据及撤销入口。
- 运行信息与隐私说明共用系统提示框，正文可选中复制；运行信息展示完整脱敏报告，仅保留关闭按钮。
- 撤销提示分为操作范围与不删除文件两段；默认取消，回车不会撤销。
- 虚拟数据界面验证：运行信息全选复制后，剪贴板含版本及脱敏报告；撤销提示按回车返回原连接状态。81 项核心回归测试通过。

- 运行信息进一步精简：移除无故障时的操作建议和固定解释，仅在存在具体问题时附恢复建议；通用验证与状态含义移入主页帮助。运行信息与隐私说明使用系统提示框原生正文，无独立文本框，并保留选中复制。

- 运行信息压缩为两段：软件与系统版本在首段，状态字段在第二段以分号分隔；有故障时将恢复建议附于第二段。软件版本标签统一为 `pmap Version`，沿用与隐私说明一致的原生提示框布局。

- 三处提示框固定为左侧应用图标、右侧标题与正文左对齐，不再依赖系统按内容长度切换布局；撤销授权仍默认取消，信息正文保留选择复制。

- 提示框宽度统一为 368 pt：正文 256、图标 64、栏间距 16、左右边距各 16。图标与标题垂直居中对齐，移除空标题栏占位；高度上限取 600 pt 与屏幕可用高度减 48 pt 的较小值，超长正文滚动。

- 主菜单统一 220 pt；格式错误保留输入并显示红色 `port/port:port`，重复端口高亮已有行。描述支持单击编辑、回车或失焦保存、Esc 取消，与端口开关分离；无描述时悬停显示编辑图标。

- 配置信任改为按需确认：普通配置直接连接；含 ProxyCommand、Match exec 或 KnownHostsCommand 时使用统一 368 pt 两栏确认框，默认取消。确认绑定展开 Include 后的内容摘要，旧版笼统信任不沿用；内容变化后重新确认，发现未确认的命令配置时关闭受管会话并保留待恢复端口。

- 状态栏端口灯按颜色加权轮播：红 2 秒、绿 1.5 秒、灰 0.5 秒；单端口也使用同一轮播流程。颜色序列变化立即重置并重新计时，无关刷新不打断当前时隙。
