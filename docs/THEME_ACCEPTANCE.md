# pmap 0.2.1 主题适配验收

## 修复范围

面板背景不再把动态系统色一次性固化为 CALayer 的 CGColor，改由 SwiftUI 跟随文字使用同一外观环境。菜单栏图标以前景所在按钮的外观决定黑白。移除渲染和调试窗口强制深色，保留现有系统外观变化监听，不新增用户设置。

开发中新增的按钮外观监听曾引发重复重绘；已移除，不包含在最终修复中。切换后测试进程 CPU 检查为 0.0%，调用栈以正常事件等待为主。

## 环境与边界

人工检查使用 macOS 27.0.1、Apple Silicon 的独立沙盒测试包和虚拟数据；测试中暂时切换系统外观，结束恢复原有深色设置。截图和日志位于 `.build-store/0.2.1-theme/evidence/`。

无标题面板截图和外观切换可读，但部分控件操作使界面工具超时；输入、编辑和信息框交互使用相同 MenuPanel 的标准调试窗口补验，不能描述为全部交互均在无标题面板完成。

macOS 26 / Intel、自动定时切换、高对比度和所有壁纸下的菜单栏对比仍需用户实机验收。本次不改变 SSH、授权或转发逻辑，未重复网络集成测试。发布版本为 0.2.1，独立于 v0.2.0，不覆盖旧标签。
