## 原生复测说明

最初的 `cgWindowNotFound` 在用户远程关闭自动锁屏后未再复现；两者存在时间上的关联，本轮未证明锁屏是唯一根因，没有为此修改程序或系统设置。

授权测试使用独立标识 `dev.local.pmap.rc6-folder` 和虚拟 `.ssh` 目录，不授权真实 SSH 文件。确认框检查只执行取消，没有执行配置中的命令。撤销后核对该独立容器：书签、所选路径和信任摘要已清除，规则、中文描述与语言保留，虚拟源文件未被修改。

测试工具最初未完整模拟中文键入，改用粘贴后中文创建和编辑正常；这不能替代各输入法的组合输入验收。预览窗口固定深色，本轮不宣称完成浅色外观或多显示器验收。授权和交互使用共用产品源码的独立测试包；最终两个候选包另行进行了上述预览检查。

新截图和检查清单位于 `.build-store/0.2.0-rc6/evidence/native-*`，仅包含虚拟数据。本次仅更新验收证据，程序和 Build 6 两个候选包均未改变，无需重复编译或运行核心回归。

## 用户验收步骤

1. 启动沙盒版，确认运行信息显示 `pmap Version 0.2.0 (Build 7)` 和 `Sandbox: true`；普通版显示 false。
2. 授权默认 `~/.ssh`，检查主机列表。若 config / known_hosts 为外部符号链接，按需授权实际目标；取消可稍后重试。
3. 选择日常主机，建立测试转发，用浏览器或客户端确认实际响应；普通配置免确认，含本机命令时默认取消的执行确认框才出现。
4. 检查 220 pt 主面板、红色格式提示、重复端口高亮、描述编辑保存与取消；单击描述不切换转发。
5. 退出后重新启动，确认授权、描述、主机及期望端口恢复。撤销授权先取消一次，再按需要确认撤销，检查端口释放和规则保留。
6. 在合适时段测试断网恢复、睡眠唤醒与实际通知设置；记录运行信息与复现步骤。
