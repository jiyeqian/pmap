真实连接验证使用临时生成的密钥，不读取用户私钥，不连接用户服务器，不修改 `~/.ssh`。为在回环环境测试连接管理，测试专用代码显式提供本机别名；正式主机过滤规则不变。

“新 Store 恢复记录”验证持久化与启动恢复代码，不等同于系统重启或物理睡眠唤醒。SSH 会话中断用于验证失联恢复，不替代所有断网场景。

## 用户验收步骤

1. 启动沙盒版，确认运行信息显示 `pmap Version 0.2.0 (Build 6)` 和 `Sandbox: true`；普通版显示 false。
2. 授权默认 `~/.ssh`，检查主机列表。若 config / known_hosts 为外部符号链接，按需授权实际目标；取消可稍后重试。
3. 选择日常主机，建立测试转发，用浏览器或客户端确认实际响应；普通配置免确认，含本机命令时默认取消的执行确认框才出现。
4. 检查 220 pt 主面板、红色格式提示、重复端口高亮、描述编辑保存与取消；单击描述不切换转发。
5. 退出后重新启动，确认授权、描述、主机及期望端口恢复。撤销授权先取消一次，再按需要确认撤销，检查端口释放和规则保留。
6. 在合适时段测试断网恢复、睡眠唤醒与实际通知设置；记录运行信息与复现步骤。
